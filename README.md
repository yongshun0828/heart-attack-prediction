Heart Attack Prediction

there are 3 files containing in the folder:

1.HeartAttackRun.py
2.HeartDataSet.csv
3.HeartPredictionMain.ipynb

-----------------------------------------------------------

HeartAttackRun.py ---> the script written to import the model to an input and output website form

HeartDataSet.csv  ---> this is the dataset

HeartPredictionMain.ipynb ----> this is the model trainning file


-----------------------------------------------------------

to run the file:

Steps:

1. open the HeartPredictionMain.ipynb , run the program inside jupyter notebook
2. after run successfully, open the anaconda prompt
3. find the location of this file stored: HeartAttackRun.py
4. insert the command into anaconda prompt: cd: C:\Users\UserName\Downloads (this is to access to the file location)
5. insert the command to run the sript: streamlit run HeartAttackRun.py
6. the program will prompt an input and output screen in website form
